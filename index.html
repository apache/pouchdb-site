The Database that Syncs!

Apache PouchDB™ is an open-source JavaScript database inspired by Apache CouchDB that is designed to run well within the browser.

PouchDB was created to help web developers build applications that work as well offline as they do online.

It enables applications to store data locally while offline, then synchronize it with CouchDB and compatible servers when the application is back online, keeping the user's data in sync no matter where they next login.

Apache PouchDB is currently undergoing Incubation at the Apache Software Foundation.

const db = new PouchDB('dbname');

db.put({
  _id: 'dave@gmail.com',
  name: 'David',
  age: 69
});

db.changes().on('change', function() {
  console.log('Ch-Ch-Changes');
});

db.replicate.to('https://example.com/mydb');

Cross Browser

Works in Firefox, Chrome, Opera, Safari, IE and Node.js

Lightweight

Apache PouchDB is just a script tag and 46KB (gzipped) away in the browser, or $ npm install pouchdb away in Node.

Easy to Learn

Requires some programming knowledge, however PouchDB is a piece of cake to learn.

Open Source

Everything is developed out in the open on GitHub, contributors always welcome!
