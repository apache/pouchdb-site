PouchDB has a new adapter - nodesqlite

By: Alba Herrerías
Published: 10 April 2026

Hello everyone! PouchDB has a new available adapter for you to use, nodesqlite, that internally uses Node.js's native SQLite module as its persistence layer. This will be, in PouchDB's release version 11.0.0, the default adapter for node environments, replacing the deprecated LevelDB ecosystem we currently depend on. You can read more about the details, discussion and timeline in this issue, and look at its implementation in this pull request.
